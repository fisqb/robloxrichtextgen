# Roblox Rich Text Generator

A rich text generator for Roblox. Create styled text with gradients, strokes, and formatting.

## Features

- Horizontal and rainbow gradients
- Color and transparency settings
- Formatting: bold, italic, underline, strikethrough
- Text stroke with adjustable width
- Line break support
- All Roblox fonts
- JSON support for RichText

## Usage

1. Enter your text
2. Customize the appearance
3. Copy the generated code

# Note

The preview is approximate and may differ slightly from how the text appears in Roblox due to differences in font rendering between browsers and the Roblox engine. Always verify the final result in-game.
