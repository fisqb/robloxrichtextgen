Tips & Help

Getting started

  • Type your text in the Text field on the left.
  • The Preview on the right updates live.
  • Copy the output using the Copy buttons.

Settings

  • Use the Language, Theme and Mode selectors next to the title.
  • Dark and Simple are the defaults. Your choices are saved between visits.
  • Switch to Advanced for all features (per-character colors, Gradient Points, Defaultio, JSON output).

Presets

  • Save, load, rename and delete presets with the buttons above.
  • Presets are stored locally in your browser.
  • Import JSON — load one or many presets from a .json file. Export — download the selected preset. Export All — download every preset in one file.

Auto-save

  • Your current text, colors, gradient points and settings are saved automatically.

Color modes

  • Solid — one color for the entire text.
  • Gradient — colors blend horizontally between Color 1 and Color 2.
  • Rainbow — full hue spectrum across the text.

Advanced features

  • Per-character colors, Gradient Points, Defaultio module output and JSON/Lua output are available in Advanced mode.
  • Click the ⛶ button to expand the preview; you can edit characters right there and pan around by dragging empty space.

Keyboard

  • Esc — close the expanded preview or this window.
  • Click outside a modal to close it.
