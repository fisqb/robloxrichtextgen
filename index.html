Tips & Help

Getting started

  • Type your text in the Text field on the left.
  • The Preview on the right updates live.
  • Copy the Rich Text, Defaultio Module Text, or JSON / Lua output using the Copy buttons.

Presets

  • Save — store the current settings under a name.
  • Load — restore the selected preset.
  • Rename — rename the selected preset.
  • Delete — remove the selected preset.
  • Presets are stored locally in your browser and persist between visits.

Auto-save

  • Your current text, colors, gradient points, and all other settings are saved automatically.
  • They are restored the next time you open the page.

Color modes

  • Solid - the whole text uses one color.
  • Gradient - colors blend horizontally between Color 1 and Color 2 across the text.
  • Rainbow - a full hue spectrum across the text (Color 1 / Color 2 are hidden).
  • Steps controls how many color stops the gradient uses (e.g. 20 steps = 20 distinct colors spread across the text).
  • Mode and its controls are hidden when Color Source is set to Gradient Points.

Color Source

  • Mode - colors come from Solid / Gradient / Rainbow settings.
  • Gradient Points - place color stops on specific characters; colors and transparency blend between neighbouring points. Overrides Mode but is overridden by per-character colors.
  • Switching between Mode and Gradient Points clears the other one's data to avoid mixing them.

Gradient Points

  • Set Color Source to Gradient Points to open the Gradient Points panel.
  • Click/tap a character to place a point there, or select an existing point.
  • Each point has its own color, and optionally its own transparency.
  • Use Delete point to remove the selected one, or Reset all points to clear them.
  • Small diamond markers above the preview show where points are placed.

Output formats

  • Roblox RichText (native) - uses <font>, <stroke>, <b>, <i>, <u>, <s>, <br/>. Paste into a TextLabel with RichText enabled.
  • Defaultio RichText Module - uses markup like <Color=r,g,b>, <Font=...>, <AnimateStyle=...>, <AnimateStepTime=...>, <AnimateStepFrequency=...>, <AnimateStepGrouping=...>, <AnimateStyleTime=...>, <StrokeColor=...>, <TextStrokeTransparency=...>, <TextTransparency=...>. Paste into the Defaultio RichText module in Studio.

Defaultio animation options

  • Animation - entrance style: Appear, Fade, Wiggle, Swing, Spin, Rainbow.
  • Animate Grouping - Letter (one by one), Word (whole words), All (everything at once).
  • Animate Step Time - seconds between animation steps.
  • Animate Step Frequency - how often to step (1 = every character, 4 = every 4th).
  • Animate Style Time - how long each entrance animation takes.

Per-character colors

  • Available when Color Source is Mode.
  • Desktop: click a character to select it. Hold & drag to select many.
  • Mobile: tap a character to toggle it. Tap several to multi-select.
  • A panel appears below the preview — pick a color and press Apply.
  • Optionally enter a Transparency (0–1) to give the selected characters a per-character transparency. Leave empty to use the global value.
  • Reset color removes colors and per-character transparency from the selected characters.
  • Reset all characters clears every custom color and per-character transparency.
  • Selected characters get an orange outline; customized ones get an orange underline.
  • Custom colors override everything else in both formats.

Formatting

  • B - bold, I - italic, U - underline, S - strikethrough.
  • Line Breaks - keep line breaks from the textarea as <br/> (Roblox) or \n (Defaultio).
  • Fix Colors - do not wrap spaces in <font> tags (Roblox only, cleaner output).

Stroke & Font

  • Stroke - outline color; Stroke Width - outline thickness (0 disables it).
  • Font - choose from Roblox-supported fonts.
  • In the Defaultio format, Stroke Width has no direct equivalent (the module only exposes stroke color and transparency), so only the stroke color is applied when thickness > 0.

Transparency

  • Global Transparency is applied once, on the outer <font face='...'> tag - it does not repeat on every character.
  • To give individual characters their own transparency, use the Character panel's Transparency field.
  • To give individual gradient points their own transparency, use the Gradient Points panel's Transparency field.
  • Nearby transparency values (difference ≤ 0.1) are merged into one group to keep the output short.
  • Defaultio format: adds <TextTransparency=...>.

Output

  • Rich Text - native Roblox RichText string.
  • Defaultio Module Text - string for the Defaultio RichText module. Only shown when that output format is selected.
  • JSON / Lua - in Roblox mode this is a JSON entry; in Defaultio mode it becomes a ready-to-paste Lua snippet that constructs the RichText object.

Keyboard

  • Esc - close this window.
  • Click outside the modal - also closes it.
